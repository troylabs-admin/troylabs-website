## Built with

- **[Astro](https://astro.build)**: static pages, fast to load
- **TypeScript** and **[React](https://react.dev)** for the interactive parts
- **[Tailwind CSS](https://tailwindcss.com)** for styling
- **[Supabase](https://supabase.com)** (Postgres) for data and sign-in
- **[Vercel](https://vercel.com)** for hosting
- **[Playwright](https://playwright.dev)** and **GitHub Actions** for automated tests on every change

The design is a 1:1 build of the TroyLabs Figma, with motion (the scrolling rocket, the star field, planets) that
respects "reduce motion".
